# 致 W. Cardwell 求醫信（Wellcome Collection Or Chinese, 13） / Chinese manuscript letter to W. Cardwell [An illustrated request for medical help]: Transcription Dataset

這封漢文求醫信由一位姓名未詳的病人撰寫，館目記受信人為傳教士 W. Cardwell。病人以文字與手繪人物描述身體多處不適，是觀察患者如何向醫療照護者描述病情的一手文獻。現藏英國 Wellcome Collection，Or Chinese, 13。

This anonymous Chinese manuscript letter asks for medical help and combines a description of bodily distress with a hand-drawn figure. Wellcome Collection catalogues W. Cardwell as the recipient. The letter provides a patient’s account of illness and help-seeking in Chinese. The source is Wellcome Collection Or Chinese, 13.

## V0.2.0

依館方一張影像，分錄正文直欄、較小旁字與圖旁題字，另標圖的位置。作者、年代與正文疑形如實標明。比對未見初稿的本機 OCR 候選後，回圖裁定採用 5 筆訂正。未定讀法及部分小字、訓點留待覆核。

The single digital image is indexed. The encoding distinguishes the main columns, marginal writing and figure labels. It identifies uncertain readings and the location of the drawing. Independent local OCR candidates were compared with the initial transcription. Targeted source-image review adopted 5 corrections. Some readings, small notes, and reading marks still need review.

## 方法與覆核 / Methods and review

由 AI 依固定館方影像逐欄讀字，保留原字、版面與疑讀。正文、旁字、手繪人物輪廓與館目著錄分層。數位件以原館連結存取。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

An AI assistant transcribed the fixed source images column by column, preserving source forms, layout and uncertain readings. Main writing, labels, the drawing and catalogue information are recorded separately. The image is available through the institutional link. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
